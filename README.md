### เจอแต่ยังไม่แก้ (รอตัดสินใจ)

- **เงินเดือนพนักงานรายวันไม่ถูกสร้างเลย** — `phr_employee.php` ใน `handleSaveSalaryPerformanceDayAuto` มี early return ที่หยุดทำงานทุกครั้งที่มีพนักงานรายวัน ดูเหมือนโค้ดทดสอบที่ลืมเอาออก แต่ถ้าลบจะเริ่มสร้างรายการเงินเดือนจริง
- **เงื่อนไขหักเงินไม่ถูกนำไปคำนวณเงินเดือน** — โค้ดส่วนนี้ถูก comment ไว้ทั้งหมดใน `phr_salary.php` และ `phr_employee.php`
- วันลานับรวมเสาร์-อาทิตย์และวันหยุด (เรื่องนโยบาย)
- รายงานยอดขาย CEO เลือกดูเดือนอื่น ยอดขายยังเป็นของเดือนปัจจุบัน (`phr_employee_sale_report.php`)
- รายงานการจ่ายเงิน เลือกทั้งพนักงานและ role แล้วตัวกรองพนักงานหาย (`phr_salary.php`)
- เลขที่ใบเตือนนับแยกต่อพนักงาน (ทุกคนได้ `P00001`)
- สถานะ "อ่านแล้ว" ของแจ้งเตือนอาจไม่ถูกบันทึก (request ถูกยกเลิกตอนเปลี่ยนหน้า)
- ไม่ตรวจว่าวันเริ่มวันหยุด ≤ วันสิ้นสุด
- อนุมัติ / ไม่อนุมัติรายการเดิมซ้ำได้ (ลางาน)
- `updateLeaveWork` ใช้งานไม่ได้หลายจุด (ยังไม่มีหน้าเรียกใช้)

### ข้อสังเกตด้าน security (ไม่ได้แก้)

- `system/api/call.php` สะท้อน `Origin` ทุกค่ากลับไปพร้อม `Access-Control-Allow-Credentials: true` ควรให้ผู้ดูแลด้าน security ตรวจสอบ
